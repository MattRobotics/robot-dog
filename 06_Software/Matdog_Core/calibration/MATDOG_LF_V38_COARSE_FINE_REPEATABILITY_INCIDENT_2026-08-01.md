# MATDOG LF V38 coarse/fine repeatability incident

Date: 2026-08-01  
Hardware result: safe fail at `LF_UPPER_M12_MIN`, step 11/14  
Mechanical change before run: none reported  
EEPROM written: no  
Global cleanup: Station stopped, serial and ports free

## Observed values

```text
coarse contact:
  target = 1393
  present = 1416
  error = 23
  current = 20
  step = 64

fine contact:
  target = 1429
  present = 1440
  error = 11
  current = 4
  step = 8

historical validated LF UPPER MIN:
  1443 / 1443

old comparison:
  circular spread(1416, 1440) = 24 ticks
  tolerance = 16 ticks
  result = contact not repeatable
```

## Root cause

The V38 motion envelope intentionally increased:

```text
TorqueLimit: 400 -> 500
GoalSpeed:   80  -> 160
Acc:         4   -> 8
coarse step: 32  -> 64 ticks
```

The contact routine still treated the coarse approach as `first_tick` and the fine approach as `second_tick`, then compared them as repeatability samples.

That comparison is invalid because the two samples were generated by different approach envelopes. With the faster V38 envelope, the coarse pass loaded the mechanical stop and drivetrain elastically to 1416 ticks, while the fine pass returned to 1440 ticks, only 3 ticks from the historical 1443 endpoint.

The safety gate correctly rejected the 24-tick difference. The design error was using the coarse scout as a metrology sample, not the rejection itself.

## Corrected production sequence

```text
coarse scouting approach
  -> contact used only to locate the stop region
  -> measurement discarded
backoff and recovery verification
fine metrology approach #1
backoff and recovery verification
fine metrology approach #2
fine #1 vs fine #2 repeatability gate
```

The repeatability tolerance remains 16 ticks. It is not widened to hide the failure.

Only the two identical fine measurements enter:

- `ContactResult`;
- MIN/MAX endpoint records;
- URDF endpoint consistency;
- model-derived q=0.

## Regression evidence

The corrected test locks the actual incident:

```text
spread(1416 coarse, 1440 fine) = 24 -> rejected
spread(1440 fine, 1443 historical fine) = 3 -> accepted
```

The same correction must be present in LF V38, LH V39 and all-legs V40 before any further hardware run.
